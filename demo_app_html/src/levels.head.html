Reading the splits

A (random) shuffles rows, so a peptide's allele and near-neighbours are usually in train. B (peptide) holds out peptides. C (allele) holds out whole alleles. C2e (cluster) holds out sequence-similarity clusters, re-assigned over the embedded rows because the original C2 leaves zero test rows on this subset. All five models see the identical 9,031 rows across 54 alleles.

The ladder starts at Level 1 because there is no Level 0 run. direct-network defaults to hla_col: hla_seq, but every committed template overrides it to hla_pseudoseq, so the full 182-residue path exists in code and was never trained. Frozen Boltz-2 embeddings take every metric on every split but one: on the random split SE+XGB edges RMSE, 11.014 against 11.297. Everywhere else the ordering is unambiguous, and on C2e it is the only representation above chance.

Two caveats worth carrying

C2e rests on 2 test clusters. The repo's own note calls it a spread rather than a point value, and the weakest-powered cell in the table. It is also the most important one, which is an argument for embedding the remaining alleles rather than leaning on the number as it stands.

SE is squeeze-and-excitation, not a new representation. squeeze-boost-network takes the direct-network feature vector unchanged — 704 channels — recalibrates it with a learned per-channel gate, then fits an MLP and an XGBoost head on the result. It belongs beside the baseline rather than above it.
